## 什么是 Agent Skills？

Agent Skills 是一种轻量、开放的格式，用于通过专业知识和 workflow 扩展 AI agent 的能力。

从根本上说，一个 skill 就是一个包含 `SKILL.md` file 的 folder。该 file 至少包含 metadata（`name` 和 `description`）以及指导 agent 完成特定 task 的 instructions。Skill 还可以打包 script、参考资料、template 和其他 resource。

```
my-skill/
├──SKILL.md # 必需：metadata + instructions
├──scripts/ # 可选：executable code
├──references/ # 可选：documentation
├──assets/ # 可选：template、resource
└──... # 任何其他 file 或 directory
```

## 为什么使用 Agent Skills？

agent 越来越有能力，但往往缺少可靠完成实际工作所需的 context。Skills 通过把流程性知识以及公司、团队和 user 专属的 context 打包成可移植、可版本控制、可按需加载的 folder 来解决这个问题。这为 agent 带来：

- **领域专业知识**：把专业知识（从法律审查流程、数据分析管道到演示文稿格式设置）沉淀为可复用的 instructions 和 resource。
- **可重复的 workflow**：把多步骤 task 转化为一致、可审计的流程。
- **跨产品复用**：只需构建一次 skill，即可在任何兼容 skills 的 agent 中使用。

## Agent Skills 如何工作？

agent 通过**progressive disclosure**分三个阶段加载 skills：

1. **discovery**：启动时，agent 只加载每个可用 skill 的名称和 description，刚好足以判断它何时可能相关。

2. **activation**：当 task 匹配某个 skill 的 description 时，agent 会把完整的 `SKILL.md` instructions 读入 context。

3. **execution**：agent 按照 instructions 执行，并可按需运行打包的代码或加载 referenced file。

完整 instructions 只会在 task 需要时加载，因此 agent 可以随时保留大量 skills，同时只占用很小的 context 空间。

## 开放开发

Agent Skills 格式最初由 [Anthropic](https://www.anthropic.com/) 开发，并以开放标准形式发布，目前已被越来越多的 agent 产品采用。该标准欢迎更广泛生态系统的贡献。

欢迎在 [GitHub](https://github.com/agentskills/agentskills) 或 [Discord](https://discord.gg/MKPE9g8aUy) 参与讨论！
