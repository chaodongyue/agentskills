在本教程中，你将创建一个 skill，让 agent 能够使用随机数生成器掷骰子。

## Prerequisites

- 安装了 [GitHub Copilot](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot) 的 [VS Code](https://code.visualstudio.com/)

<Note>
本教程使用 VS Code，但 Agent Skills 是开放格式。同一个 skill 可以在任何兼容的 agent 中运行，包括 Claude Code 和 OpenAI Codex。
</Note>

## 创建 skill

一个 skill 是一个包含 `SKILL.md` file 的 folder。 VS Code 默认在 `.agents/skills/` 中查找 skills。在你的项目中创建 `.agents/skills/roll-dice/SKILL.md`：

````markdown .agents/skills/roll-dice/SKILL.md
---
name: roll-dice
description: 使用随机数生成器掷骰子。当被要求掷一个骰子（d6、 d20 等）、掷骰子或生成随机骰子结果时使用。
---

要掷一个骰子，请使用以下命令生成从 1 到指定面数之间的随机数：

```bash
echo $((RANDOM % <sides> + 1))
```

```powershell
Get-Random -Minimum 1 -Maximum (<sides> + 1)
```

将 `<sides>` 替换为骰子的面数（例如，标准骰子为 6，d20 为 20）。
````

就这样，一个不到 20 行的 file。以下是各部分的作用：

- **`name`**：skill 的短标识符。必须与 folder 名称匹配。
- **`description`**：告诉 agent 何时使用这个 skill。 agent 会据此决定是否 激活它。
- **正文**：skill 激活后 agent 要遵循的 instructions。这里的 instructions 要求 agent 使用终端命令生成随机数，并把user 请求中的面数代入命令。

## 试用

1. 在 VS Code 中打开你的项目。
2. 打开 Copilot Chat 面板。
3. 从聊天面板底部的模式下拉菜单中选择 **Agent** 模式。
4. 输入 `/skills`，确认 `roll-dice` 出现在列表中。如果没有，请检查该 file 是否位于相对于项目根 directory 的 `.agents/skills/roll-dice/SKILL.md`。
5. 提问：**"Roll a d20"**

agent 应该会激活 `roll-dice` skill。它可能会请求运行终端命令的 permission，请允许它。它会运行命令并返回 1 到 20 之间的随机数。

<Note>
不同 model 的 tool 使用可靠性有所差异。有些 model 会稳定地遵循 skill instructions 并运行命令，另一些 model 可能会尝试自行回答。如果 agent 没有运行终端命令就直接回复，请尝试从 model 下拉菜单中选择另一个 model。
</Note>

## 工作原理

幕后发生了这些事情：

1. **discovery**：聊天 session 启动时，agent 扫描默认 skill directory 并找到了你的 skill。它只读取了 `name` 和 `description`，刚好足以判断这个 skill 什么时候可能相关。

2. **activation**：当你询问掷骰子时，agent 将你的问题与 skill 的 description 匹配，并把完整的 `SKILL.md` 正文加载到 context 中。

3. **execution**：agent 按照正文中的 instructions，将终端命令调整为你请求中的骰子面数。

这个过程使用**progressive disclosure**，让 agent 可以访问许多 skills，而无需一开始就加载它们的全部 instructions。
